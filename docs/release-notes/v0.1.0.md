First public release of **Tickrate**, a Windows optimizer focused on input latency and frame pacing in **Fortnite** and **VALORANT**, tuned for **NVIDIA** GPUs and **AMD Ryzen X3D** CPUs.

## Download

| File | Use it if |
|---|---|
| `Tickrate-Setup-0.1.0.exe` | You want a normal install with a Start-menu entry and an uninstaller. |
| `Tickrate-Portable-0.1.0.exe` | You want a single exe that runs without installing. |

Both need **administrator rights** and Windows 10/11 x64. The app is not code-signed yet, so Windows SmartScreen will warn on first launch: choose *More info → Run anyway*.

## What's in it

- **PC scan:** EXPO/XMP off, monitor below max refresh, single-channel RAM, GPU PCIe width, Resizable BAR, driver age, forced HPET, wrong power plan for your CPU, anti-cheat readiness (Secure Boot, TPM, VBS, Memory Integrity) and background load. Each finding has a one-click fix or a guide.
- **56 documented tweaks** in 12 categories with *Essential*, *Competitive* and *Everything* presets. Each shows what it does, why, and exactly what it changes.
- **Ryzen X3D aware:**
  - Dual-CCD chips (7950X3D / 9950X3D and the 9-series siblings) keep the Balanced plan, Game Mode and Game Bar, which AMD's core parking needs, and Fortnite and VALORANT are pinned to the V-Cache CCD.
  - Single-CCD chips (7800X3D / 9800X3D) get a dedicated low-latency power plan.
- **NVIDIA Profile Inspector integration:** backs up your driver profile, applies the settings, reads them back to verify, and restores your original in one click.
- **Cleanup, Store-app debloat, startup manager and Windows repair tools.**
- **Safety:** a System Restore point before your first change each session, an exact per-value backup of everything changed, per-tweak revert and "Revert everything".

## Before you start

- Apply the **Essential** preset first and play a few matches before moving to Competitive.
- On Windows test machines, every tweak was applied and reverted with all original values restored. It has **not** been tested on real NVIDIA + X3D hardware yet, so the X3D tweaks, the NVIDIA profile and the network-adapter tweaks are the least proven. Please report anything odd in [Issues](https://github.com/Jargyliu/optimizer/issues), with the log from `%ProgramData%\Tickrate\logs`.
- Disabling VBS / Memory Integrity is deliberately **not** included: VALORANT's Vanguard On-Demand mode and Fortnite PC tournaments check for these security features.
