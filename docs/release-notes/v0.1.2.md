Fixes Cleanup breaking the app when "Your temp files" is selected.

## Fixed

- **"ENOENT: no such file or directory" after a cleanup.** Tickrate's engine exchanged its messages through files in `%TEMP%\tickrate`, and cleaning "Your temp files" deleted that folder while the cleanup was still running. The cleanup itself completed, but its result was lost and every later action failed until a restart. Engine messages now live in `%ProgramData%\Tickrate\ipc`, the folder is recreated if it ever goes missing, and Cleanup never touches Tickrate's own files.

## Changed

- **Temp cleanup keeps files from the last 24 hours**, similar to Windows' own Disk Cleanup. Recent temp files can belong to an installer or app that is still running.
- Removed the harmless "Waiting for service BITS to start" warning from the activity log.
- A new Windows CI test checks that cleanup removes old temp files, keeps recent ones, and leaves Tickrate's working files alone.

## Download

Install **`Tickrate-Setup-0.1.2.exe`** over your current version. Your backups and applied tweaks are kept.
