Fixes the app going blank right after "Scanning your PC" finishes.

## Fixed

- **Blank window after the first scan.** On PCs with a single GPU or a single monitor (most PCs), Windows PowerShell sent those lists to the app as one object instead of a list, and the interface crashed while drawing the results. The engine now always sends lists, and the interface accepts either shape. The same issue could also hit the Startup apps and Power plans pages, and is fixed there too.

## Improved

- If any screen ever hits an error, Tickrate now shows what went wrong with **Try again** and **Copy details** buttons instead of a blank window.
- Interface errors and renderer crashes are written to `%ProgramData%\Tickrate\logs`, so problems can be diagnosed.
- CI now checks that the real Windows scan returns proper lists, and demo mode has a `?psjson` switch that reproduces Windows PowerShell's data shapes for testing.
